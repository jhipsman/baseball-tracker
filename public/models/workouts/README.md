# Workout motion asset

`dumbbell-squat.glb` is a shortened, converted motion-capture clip from Anderson Rohr's [Mocap Pack 06: Fitness and Workout](https://andersonrohr.gumroad.com/l/mocap_pack6). The source pack's terms permit use in personal and commercial projects but prohibit redistributing or selling the pack as a standalone product. This file is integrated into the workout demonstration and is not a standalone pack.

The app adds dumbbells to the mannequin's hands. The clip is not intended to replace a coach's instruction.
