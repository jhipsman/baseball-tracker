# GameChanger analysis download

Download **GameChanger-Analysis-Complete.zip**: open that file above and click **Download raw file** (the download arrow). On Windows, right-click the downloaded ZIP and choose **Extract All**. Open **START-HERE.txt** in the extracted folder.

The complete ZIP includes the reports, supporting evidence, validation cases and sample scorebook. The main reports are also readable directly in this branch. This branch contains only analysis artifacts; it is separate from the app branch.
