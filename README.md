# Analysis downloads

Open a ZIP below on GitHub and click **Download raw file** (the download arrow). On Windows, right-click the downloaded ZIP and choose **Extract All**.

## LeagueApps

[LeagueApps-Reference-Pack.zip](LeagueApps-Reference-Pack.zip) contains the research report, screenshot gallery, images and source references. After extracting, open **gallery-local.html** in a browser to view the screenshots, or **REPORT.md** for the analysis. [Read the report on GitHub](LEAGUEAPPS_REPORT.md).

## GameChanger

[GameChanger-Analysis-Complete.zip](GameChanger-Analysis-Complete.zip) contains the reports, supporting evidence, validation cases and sample scorebook. After extracting, open **START-HERE.txt**. [Read the report on GitHub](REPORT.md).

This branch contains only analysis artifacts and is separate from the app branch. Deployment is disabled for this branch.
